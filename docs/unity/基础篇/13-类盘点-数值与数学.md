# 13　类盘点（一）：数值、向量与数学

你说 `Vector3` 看不懂——它确实是个"没人教就会懵"的东西。这一章把它从头讲清楚，顺带把 Unity 里所有常用的**数值类型**过一遍。

## 13.1 先搞懂：struct 是"值"，不是"引用"

`Vector3`、`Vector2`、`Color`、`Quaternion`、`Rect` 这些在 Unity 里都是 **`struct`（结构体 / 值类型）**，不是 `class`。

区别用一句话说：

| | class（引用类型） | struct（值类型） |
| --- | --- | --- |
| 赋值时 | 复制**引用**（两个变量指向同一个对象） | 复制**整个值**（两份独立的数据） |
| 典型 | `GameObject`、`Transform`、`MonoBehaviour` | `Vector3`、`Color`、`Quaternion`、`Rect` |

**这带来一个经典坑**：

```csharp
transform.position.x = 5f;      // ❌ 编译错误：无法修改返回值
```

为什么？因为 `transform.position` 返回的是"当前位置的一个**副本**"，你改副本毫无意义。

正确写法：

```csharp
Vector3 p = transform.position;   // 拿到副本
p.x = 5f;                         // 改副本
transform.position = p;           // 再整体写回去

// 或者一行：
transform.position = new Vector3(5f, transform.position.y, transform.position.z);
```

> 记住这条："**Unity 里凡是返回 `Vector3`/`Color` 的属性，都不能直接改它的字段**"。

## 13.2 Vector3：三个数 = 点 / 方向 / 位移

### 它是什么

```csharp
public struct Vector3
{
    public float x;
    public float y;
    public float z;
}
```

就三个 `float`。Unity 用它表达三种东西（**同一个类型，语义靠上下文**）：

| 语义 | 例子 |
| --- | --- |
| **位置（点）** | `transform.position = new Vector3(1, 2, 0)` |
| **方向** | `Vector3.up`（向上）、`(target - self).normalized` |
| **位移** | `transform.position += Vector3.right * speed * Time.deltaTime` |

2D 里 `z` 通常写 0。

### 最常用的属性

| 属性/常量 | 含义 |
| --- | --- |
| `Vector3.zero` | `(0,0,0)` |
| `Vector3.one` | `(1,1,1)` |
| `Vector3.up` / `down` | `(0,1,0)` / `(0,-1,0)` |
| `Vector3.right` / `left` | `(1,0,0)` / `(-1,0,0)` |
| `Vector3.forward` / `back` | `(0,0,1)` / `(0,0,-1)` |
| `v.magnitude` | 向量长度（距离） |
| `v.sqrMagnitude` | 长度的平方（**比较距离时用它更快**，因为不用开方） |
| `v.normalized` | 单位向量（长度变 1，方向不变） |

### 运算符

```csharp
Vector3 a = new Vector3(1, 2, 0);
Vector3 b = new Vector3(3, 0, 0);

Vector3 sum  = a + b;        // (4,2,0)   位移叠加
Vector3 diff = a - b;        // (-2,2,0)  从 b 指向 a 的方向
Vector3 s    = a * 2f;       // (2,4,0)   缩放
Vector3 d    = a / 2f;       // (0.5,1,0)
bool    eq   = a == b;       // 近似比较（不是精确相等！）
```

> **`==` 是"近似相等"**：Unity 内部用 `1e-5` 的容差比较，因为浮点数算出来经常是 `0.9999999`。所以**不要用 `==` 比较位置是否"精确相等"**，要么用 `Vector3.Distance(a,b) < 0.01f`，要么用 `Vector3.SqrMagnitude(a-b) < 0.0001f`。

### 最常用的静态方法

```csharp
// 距离（两个点的距离）
float dist = Vector3.Distance(a, b);

// 线性插值：t=0 返回 a，t=1 返回 b（做平滑移动/淡入淡出）
Vector3 mid = Vector3.Lerp(a, b, 0.5f);
Vector3 smooth = Vector3.Lerp(a, b, Mathf.SmoothStep(0f, 1f, t));

// 朝目标匀速移动（不会超过目标）
transform.position = Vector3.MoveTowards(transform.position, target, speed * Time.deltaTime);

// 点积 / 叉积
float dot = Vector3.Dot(a, b);        // 判断"朝向夹角"
Vector3 cross = Vector3.Cross(a, b);  // 判断"在左边还是右边"（2D 常用 z 的符号）

// 限制长度（比如摇杆输入最大为 1）
Vector3 clamped = Vector3.ClampMagnitude(input, 1f);

// 角度（两个方向之间的夹角）
float angle = Vector3.Angle(dirA, dirB);
```

### 2D 里常用的写法

```csharp
Vector3 pos = transform.position;

// 向右移动
pos.x += speed * Time.deltaTime;

// 限制在屏幕内
pos.x = Mathf.Clamp(pos.x, -7.5f, 7.5f);

transform.position = pos;
```

### 坑

- **`normalized` 对零向量返回零**，不会报错但也得不到方向。要用方向前先判断长度。
- **频繁 `magnitude` 有开销**（要开方）。循环里比较距离用 `sqrMagnitude`。
- `Vector3` 是值类型：函数传参是复制，**改动不会影响原变量**。

## 13.3 Vector2 与 Vector2Int

### Vector2

就是"没有 z 的 Vector3"，2D 里更常用（UI、2D 物理、输入）。

```csharp
Vector2 input = new Vector2(Input.GetAxisRaw("Horizontal"), Input.GetAxisRaw("Vertical"));

// 和 Vector3 互转（隐式转换）
Vector3 v3 = input;                  // 自动补 z = 0
Vector2 v2 = transform.position;     // 自动丢掉 z

// 常用常量与属性
Vector2.zero / one / up / down / left / right
input.magnitude / sqrMagnitude / normalized

// 2D 专用：朝向角度
float angle = Mathf.Atan2(input.y, input.x) * Mathf.Rad2Deg;
```

> **2D 物理里用 `Vector2`，Transform 里用 `Vector3`**：`rb.velocity` 是 `Vector2`，`transform.position` 是 `Vector3`。混用时靠隐式转换，注意 z 会被补 0（2D 里没问题）。

### Vector2Int / Vector3Int

整数版本（x、y、z 都是 `int`），用于**网格坐标**（棋盘格、Tilemap、格子寻路）。

```csharp
Vector2Int cell = new Vector2Int(3, 5);
Vector3 world = new Vector3(cell.x, cell.y, 0f);      // 格子坐标 → 世界坐标
```

**注意**：`Vector2` 和 `Vector2Int` **不能隐式互转**（会丢精度），要显式：

```csharp
Vector2Int i = new Vector2Int(Mathf.RoundToInt(v.x), Mathf.RoundToInt(v.y));
Vector2 f = new Vector2(i.x, i.y);
```

## 13.4 Quaternion：旋转（四元数）

### 它是什么

表示"一个朝向"的数学对象。**为什么不用欧拉角（x/y/z 度数）**：欧拉角在特定角度会出现"万向节死锁"（旋转卡住、跳变），四元数没有这个问题，插值也更平滑。

### 常用接口

```csharp
// 用欧拉角创建（最直观，2D 最常用）
transform.rotation = Quaternion.Euler(0f, 0f, 45f);

// 无旋转
transform.rotation = Quaternion.identity;

// 2D：朝向某点
Vector2 d = target.position - transform.position;
float angle = Mathf.Atan2(d.y, d.x) * Mathf.Rad2Deg;
transform.rotation = Quaternion.Euler(0f, 0f, angle - 90f);   // -90 取决于贴图朝向

// 插值（角度过渡）
transform.rotation = Quaternion.Slerp(transform.rotation, targetRot, Time.deltaTime * 5f);

// 读当前角度（注意：拿到的是副本）
Vector3 euler = transform.rotation.eulerAngles;
```

### 坑

- **不能直接改 `rotation.x` 之类**（四元数的四个分量不是角度，乱改会出鬼）。
- `transform.rotation.eulerAngles` 返回副本，改它没用。
- `Quaternion.Lerp` 在角度差大时可能绕远路；**旋转一般用 `Slerp`**。
- 2D 里想"只转 Z 轴"，用 `Quaternion.Euler(0, 0, angle)` 最省事。

## 13.5 Color 与 Color32

### 两个类型

| | `Color` | `Color32` |
| --- | --- | --- |
| 分量范围 | 0~1 的 `float` | 0~255 的 `byte` |
| 用处 | 代码里调色、插值 | 内存/传输更省（批量贴图） |
| 转换 | `(Color)c32` / `(Color32)c` | 自动 |

```csharp
Color alpha = new Color(1f, 0f, 0f, 0.5f);      // 最后一个参数是 a（透明度）
Color32 hex = new Color32(0xFF, 0x64, 0x32, 0xFF);

Color lerped = Color.Lerp(Color.white, Color.red, 0.5f);
Color withAlpha = new Color(c.r, c.g, c.b, 0.3f);

sr.color = new Color(1f, 1f, 1f, 0.5f);          // 半透明染色
```

### 坑

- **改透明度忘设 a**：`new Color(1,1,1)` 的 a 默认是 1（不透明）。
- **颜色会相乘**：Sprite 本身带颜色 + `sr.color` 染色 → 结果比预期暗。
- UI 的 `Image.color` 也是 `Color`（0~1）。

## 13.6 Rect 与 Bounds

### Rect（2D 矩形）

```csharp
Rect r = new Rect(x, y, width, height);
r.xMin / r.xMax / r.yMin / r.yMax      // 四条边
r.center / r.size
r.Contains(new Vector2(1, 2))          // 点在矩形内？

// UI 元素的屏幕矩形
Rect screenRect = RectTransformUtility.RectangleToScreen(rt);
```

### Bounds（包围盒）

```csharp
Bounds b = renderer.bounds;
b.center / b.size / b.extents
b.Contains(point)
b.Intersects(otherBounds)
```

**用处**：判断物体是否在摄像机视野内、粗略碰撞、物体被裁剪时隐藏。

## 13.7 Mathf：数学工具箱

Unity 的数学函数都在这（避免用 `System.Math` 时 double/float 来回转）。

| 函数                                         | 作用                 | 例子                   |
| ------------------------------------------ | ------------------ | -------------------- |
| `Mathf.Abs`                                | 绝对值                | `Mathf.Abs(-3) == 3` |
| `Mathf.Clamp(v, min, max)`                 | 夹在范围内              | 边界限制                 |
| `Mathf.Clamp01(v)`                         | 夹在 0~1             | 进度条                  |
| `Mathf.Lerp(a, b, t)`                      | 线性插值               | 渐变                   |
| `Mathf.LerpUnclamped`                      | 不夹 t（t 可以超 0~1）    | 弹性效果                 |
| `Mathf.InverseLerp(a, b, v)`               | 反推 t（v 在 a~b 的百分比） | 血量百分比                |
| `Mathf.MoveTowards(cur, target, maxDelta)` | 匀速接近               | 平滑跟随                 |
| `Mathf.SmoothStep(0,1,t)`                  | 缓动曲线               | 更自然的过渡               |
| `Mathf.Round / Floor / Ceil`               | 取整                 |                      |
| `Mathf.RoundToInt`                         | 四舍五入到 int          | 格子坐标                 |
| `Mathf.Pow / Sqrt`                         | 幂/开方               |                      |
| `Mathf.Sin / Cos`                          | 三角函数（弧度）           | 波动动画                 |
| `Mathf.Atan2(y, x)`                        | 由向量求角度             | 朝向                   |
| `Mathf.Rad2Deg / Deg2Rad`                  | 弧度↔角度              |                      |
| `Mathf.PingPong(t, length)`                | 来回摆动               | 呼吸/循环                |
| `Mathf.Repeat(t, length)`                  | 循环取余               |                      |
| `Mathf.Approximately(a, b)`                | 近似相等               | 浮点比较                 |
| `Mathf.Infinity`                           | 正无穷                | 最大值                  |

### 两个最常用的组合

```csharp
// 进度 → 平滑值
float t = Mathf.Clamp01(elapsed / duration);
float eased = Mathf.SmoothStep(0f, 1f, t);
Vector3 pos = Vector3.Lerp(start, end, eased);

// 血量百分比
float hpPercent = Mathf.InverseLerp(0f, maxHp, currentHp);
```

> **`Mathf` 的参数都是 `float`**，传 `double` 会隐式转换（可能丢精度）；传 `int` 会转成 float 再返回（用 `Mathf.RoundToInt` 拿 int）。

## 13.8 Random：随机数（Unity 版）

**注意**：Unity 的是 `UnityEngine.Random`，和 `System.Random` **不是一回事**。

```csharp
// 整数：左闭右开！Range(0, 10) 返回 0~9，永远不到 10
int i = Random.Range(0, 10);

// 浮点：两端都包含
float f = Random.Range(0f, 1f);      // 可能等于 1f

// 常用
Random.value                         // 0~1
Random.insideUnitCircle              // 半径 1 的圆内的随机点（Vector2）
Random.insideUnitSphere              // 球内随机点（Vector3）
Random.rotation                      // 随机旋转
Random.ColorHSV()                    // 随机颜色

// 可复现（同一个种子 → 同样的序列，测试/分享地图时有用）
Random.InitState(12345);
```

### 坑

- **`Random.Range(int, int)` 是左闭右开**，所以 `Random.Range(0, 4)` 得到 0~3 ✓（正好当网格下标）
- **`using System;` 之后写 `Random.Range` 会歧义**（`System.Random` 是类，`Range` 不是它的静态方法 → 编译错误）。这时写全名 `UnityEngine.Random.Range(...)`，或者不要 `using System;`。
- 每个对象各自 `new Random()` 会导致**相同种子**（时间精度问题），生成大量对象时用 Unity 的静态 `Random`。

## 13.9 Time：时间

| 属性 | 含义 | 用途 |
| --- | --- | --- |
| `Time.deltaTime` | 上一帧耗时（秒） | **移动、动画必须乘它** |
| `Time.time` | 游戏开始到现在的秒数 | 计时 |
| `Time.unscaledDeltaTime` | 不受 `timeScale` 影响的帧耗时 | UI 动画（暂停时也要动） |
| `Time.timeScale` | 时间流逝倍率（0 = 暂停，2 = 两倍速） | 暂停、慢动作 |
| `Time.fixedDeltaTime` | 固定帧间隔（默认 0.02） | `FixedUpdate` 里的计算 |
| `Time.frameCount` | 已过的帧数 | 每 N 帧做一次 |
| `Time.realtimeSinceStartup` | 真实时间（不受暂停影响） | 性能统计 |

```csharp
// 暂停
Time.timeScale = 0f;

// 恢复
Time.timeScale = 1f;

// 慢动作
Time.timeScale = 0.3f;

// 暂停时也要动的协程等待
yield return new WaitForSecondsRealtime(1f);
```

### 坑

- **暂停时 `Time.deltaTime` 变 0**，所有基于它的移动都会停——这通常是想要的；但 UI 动画不想停，就要用 `unscaledDeltaTime`。
- **协程里 `WaitForSeconds` 受 `timeScale` 影响**，暂停时会一直等下去。
