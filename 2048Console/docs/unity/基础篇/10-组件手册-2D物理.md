# 10　组件手册（二）：2D 物理

2D 物理就两个主角：**Rigidbody2D（谁受物理控制）** 和 **Collider2D（形状是什么）**。其余都是配件。

## 10.1 先建立模型

| 组件 | 角色 | 不挂会怎样 |
| --- | --- | --- |
| `Rigidbody2D` | "物理参赛者"：受重力、速度、碰撞反应控制 | 对象是"静态的"，不会被推动、也不产生碰撞反馈 |
| `Collider2D` | "形状"：告诉物理系统"我多大、什么形状" | 物理系统不知道它存在，**完全不会碰撞** |

**记住一条硬规则**：一次碰撞/触发，**至少一方要带 `Rigidbody2D`**。两个都没有刚体的 Collider 之间永远不产生回调。

## 10.2 Rigidbody2D

### Body Type（最重要）

| 类型 | 受重力/力 | 会被别的物体推动 | 适合 |
| --- | --- | --- | --- |
| **Dynamic**（动态） | ✅ | ✅ | 玩家、掉落物、球、能被撞飞的东西 |
| **Kinematic**（运动学） | ❌（自己用代码移动） | ❌（但会推动 Dynamic） | 移动平台、可控但不物理的物体 |
| **Static**（静态） | ❌ | ❌ | 墙、地面（**其实可以完全不挂刚体**，挂 Static 也行） |

### 关键属性

| 属性 | 含义 |
| --- | --- |
| `bodyType` | 上面三种 |
| `gravityScale` | 重力倍数（0 = 不受重力；2 = 两倍） |
| `mass` | 质量（影响碰撞时的动量） |
| `linearDamping` | 线性阻尼（速度衰减，类似空气阻力） |
| `angularDamping` | 旋转阻尼 |
| `constraints` | 冻结某些轴：`Freeze Rotation Z` 最常用（防止方块翻滚） |
| `collisionDetectionMode` | `Discrete`（默认）/ `Continuous`（高速物体防穿透，子弹必用） |
| `interpolation` | 插值（`None` / `Interpolate` / `Extrapolate`），视觉更顺滑 |
| `sleepMode` | 静止后休眠省性能（默认 `Start Awake`） |

### 代码怎么用

```csharp
Rigidbody2D rb = GetComponent<Rigidbody2D>();

// 直接设速度（最常用）
rb.velocity = new Vector2(5f, rb.velocity.y);

// 施力（适合物理感的手感）
rb.AddForce(new Vector2(0f, 500f));
rb.AddForce(Vector2.up * 500f, ForceMode2D.Impulse);   // 冲量（一次性的力）

// 跳跃惯用写法
if (Input.GetKeyDown(KeyCode.Space) && isGrounded)
{
    rb.velocity = new Vector2(rb.velocity.x, jumpSpeed);
}

// 用 MovePosition 移动 Kinematic 刚体（会参与物理检测）
rb.MovePosition(rb.position + Vector2.right * speed * Time.fixedDeltaTime);

// 冻结旋转（也可以在 Inspector 里设 Constraints）
rb.constraints = RigidbodyConstraints2D.FreezeRotation;
```

> **版本提示**：2022.3 用 `rb.velocity`。如果你以后升级到 Unity 6，它会被改名为 `rb.linearVelocity`（旧名仍可用但有警告）——到时全局替换一下即可。

### 坑

- **在 `Update` 里改速度会抖**：物理应该在 `FixedUpdate` 里操作（`Update` 每帧一次，物理按固定步长算）。
- **`transform.position` 直接改 Dynamic 刚体 = 硬传送**，会破坏碰撞检测。用 `rb.MovePosition` 或直接改 `velocity`。
- 忘了 `Freeze Rotation Z` → 方块会边掉边转（8.12 那个接球游戏就踩过）。

## 10.3 Collider2D 家族

| 类型 | 形状 | 用在 |
| --- | --- | --- |
| `Box Collider 2D` | 矩形 | 方块、平台、墙（**最常用**） |
| `Circle Collider 2D` | 圆 | 球、子弹、爆炸范围 |
| `Capsule Collider 2D` | 胶囊 | 角色（圆角矩形） |
| `Polygon Collider 2D` | 任意多边形 | 不规则地形（能自动生成轮廓） |
| `Edge Collider 2D` | 一条折线（无厚度） | 平台边界、地形轮廓 |
| `Composite Collider 2D` | 把多个 Collider 合并 | 瓦片地图合成一整块（性能） |

### 关键属性

| 属性 | 含义 |
| --- | --- |
| `isTrigger` | 勾上 = **只检测重叠，不物理阻挡**（详见 10.5） |
| `offset` | 碰撞体相对对象原点的偏移 |
| `material` | 物理材质（摩擦/弹性，见 10.4） |
| `usedByComposite` | 是否参与 Composite 合并（Tilemap 常用） |
| `density` | 密度（影响质量） |

### 什么时候用 Trigger

| 需求 | 用哪种 |
| --- | --- |
| 撞墙停下、被弹开 | **不用** Trigger（勾掉） |
| 拾取道具、进入区域、接住东西、死亡判定 | **勾上** Trigger |

## 10.4 Physics Material 2D：摩擦和弹性

新建：`Assets` 右键 → `Create → 2D → Physics Material 2D`

| 属性 | 含义 | 例子 |
| --- | --- | --- |
| `friction` | 摩擦（0 = 冰面，1 = 很粘） | 冰面 0，普通地面 0.4 |
| `bounciness` | 弹性（0 = 不反弹，1 = 完全反弹） | 皮球 0.8，木箱 0 |

把材质拖到 Collider2D 的 `Material` 字段上。两边都有材质时，Unity 会取平均。

## 10.5 碰撞与触发回调

四个回调，成对记忆：

| 回调 | 什么时候调用 | 前提 |
| --- | --- | --- |
| `OnCollisionEnter2D(Collision2D col)` | **实体碰撞**开始的那一帧 | 双方都不是 Trigger |
| `OnCollisionStay2D` | 持续接触期间，每 `FixedUpdate` 一次 | 同上 |
| `OnCollisionExit2D` | 分开的那一帧 | 同上 |
| `OnTriggerEnter2D(Collider2D other)` | **触发重叠**开始的那一帧 | 至少一方是 Trigger |
| `OnTriggerStay2D` | 重叠期间每帧 | 同上 |
| `OnTriggerExit2D` | 分开的那一帧 | 同上 |

### 三个硬性条件（缺一条就没有回调）

1. 参与的**至少一方带 `Rigidbody2D`**
2. 至少一个是 Trigger（用 Trigger 回调时）
3. 双方在 `Project Settings → Physics 2D → Layer Collision Matrix` 里**允许碰撞**

### 回调里能拿到什么

```csharp
private void OnCollisionEnter2D(Collision2D col)
{
    Debug.Log($"撞到了 {col.gameObject.name}");
    Debug.Log($"撞击力 {col.relativeVelocity.magnitude}");   // 撞击速度
    ContactPoint2D p = col.GetContact(0);                    // 接触点
    Vector2 normal = p.normal;                               // 法线（判断撞墙/撞地）
}

private void OnTriggerEnter2D(Collider2D other)
{
    // 用 TryGetComponent 判断对方是什么，比 Tag 更稳（不会因为忘设 Tag 而失败）
    if (other.TryGetComponent<Coin>(out var coin))
    {
        coin.Collect();
        Destroy(other.gameObject);     // 不销毁的话对象会一直挡着
    }
}
```

> **`Enter` 只在开始重叠那一帧调用一次**。多数情况在 Enter 里处理完就 `Destroy` 或改状态即可，不要用 `Stay`（每帧触发，容易导致分数狂涨）。

### 碰撞 vs 触发：怎么选

| 想要的效果 | 选择 |
| --- | --- |
| 挡住、弹开、推动 | 关掉 `Is Trigger` |
| 穿过但"知道了" | 勾上 `Is Trigger` |
| 既要物理又想知道状态 | 加两个 Collider：一个实体一个 Trigger（进阶做法） |

## 10.6 Layer 与碰撞矩阵

**Layer（层）** 是给对象分类的标签（`Edit → Project Settings → Tags and Layers`）。

| 用途 | 例子 |
| --- | --- |
| 只让某些层互相碰撞 | 玩家子弹不撞玩家自己 |
| 摄像机 Culling Mask | UI 相机只拍 UI 层 |
| 射线过滤 | `Physics2D.Raycast(..., layerMask)` |

`Project Settings → Physics 2D → Layer Collision Matrix` 决定哪些"层对"会产生碰撞。默认全勾，自定义层后要记得调整。

```csharp
gameObject.layer = LayerMask.NameToLayer("Player");
int playerMask = LayerMask.GetMask("Player");
```

### 坑

- **"玩家子弹打到自己"**：层还是 Default，矩阵全勾。
- 改了层名后，硬编码数字会静默失效。

## 10.7 物理查询：射线和范围检测

不做碰撞、只想"检测一下某个方向/范围里有什么"时用这些（做瞄准、地面检测、爆炸范围）。

```csharp
// 射线：从起点沿方向打一条线，返回第一个命中
RaycastHit2D hit = Physics2D.Raycast(transform.position, Vector2.down, 1.2f);
if (hit.collider != null)
{
    Debug.Log($"脚下是 {hit.collider.name}");
}

// 只检测某个层
int groundMask = LayerMask.GetMask("Ground");
hit = Physics2D.Raycast(transform.position, Vector2.down, 1.2f, groundMask);

// 圆形范围检测（拾取、爆炸）
Collider2D[] hits = Physics2D.OverlapCircleAll(transform.position, 3f);

// 盒子范围检测
Collider2D[] boxes = Physics2D.OverlapBoxAll(transform.position, new Vector2(2, 2), 0f);
```

**调试射线**：`Debug.DrawRay(origin, dir * length, Color.red)` 在 Scene 视图里画出射线，配合 `OnDrawGizmos` 更好用。

## 10.8 关节与效应器（了解即可）

| 组件 | 作用 |
| --- | --- |
| `Hinge Joint 2D` | 铰链（门、摆锤） |
| `Distance Joint 2D` | 保持距离（绳子、链条） |
| `Spring Joint 2D` | 弹簧 |
| `Fixed Joint 2D` | 刚性连接 |
| `Area Effector 2D` | 区域内力（风、水流） |
| `Platform Effector 2D` | 单向平台（从下往上能穿过去） |
| `Point Effector 2D` | 吸引/排斥（黑洞） |

这些等你做具体玩法时再查，不必一开始全记。

## 10.9 排查清单：为什么没碰撞 / 没触发

按顺序查，90% 能解决：

1. **双方至少一个有 `Rigidbody2D` 吗？**（最常见的遗漏）
2. **该勾 `Is Trigger` 的勾了吗？**（要触发检测却两个都是实体，走的是 `OnCollision*` 而不是 `OnTrigger*`）
3. **回调名字写对了吗？**（`OnTriggerEnter2D`，带 2D，参数是 `Collider2D`）
4. **回调写在带 Collider 的对象上的脚本里吗？**（至少一方要写）
5. **Layer 碰撞矩阵允许吗？**
6. **对象在运行中被 `SetActive(false)` 了吗？**（禁用对象不参与物理）
7. **Collider 的尺寸对吗？**（Scene 视图里能看到绿色轮廓，调到和贴图一致）

## 10.10 本章练习

1. **弹跳球**：地面（BoxCollider2D + Static）+ 球（CircleCollider2D + Dynamic + 反弹材质）
2. **掉落重置**：坑用 Trigger，球进坑时 `Debug.Log` 并把它移回起点
3. **子弹穿透对比**：子弹 Rigidbody2D 分别设 `Discrete` 和 `Continuous`，撞墙后 `Destroy`，观察高速时是否穿模
4. **地面检测**：用 `Physics2D.Raycast` 判断脚下是否有地面（用于跳跃）
5. 用 `OnDrawGizmos` 把射线可视化
