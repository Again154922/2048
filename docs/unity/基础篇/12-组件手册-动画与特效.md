# 12　组件手册（四）：动画、特效与声音

## 12.1 做动画的三条路

| 方式 | 适合 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **代码/协程**（`transform`、`Mathf.Lerp`） | 简单的位移、缩放、颜色渐变 | 灵活、无需资源 | 复杂动画写起来累 |
| **Animator**（动画状态机） | 角色动作、循环动画、多状态切换 | 美术可编辑、可视化调试 | 需要学状态机；改参数要开窗口 |
| **DOTween / LitMotion 等插件** | 补间动画（Tween） | 一行代码做缓动 | 第三方依赖 |

**2048 这种项目**：大部分用协程（你已经会了），选项面板的弹出可以用 Animator 或协程。

## 12.2 Animator 入门

### 三个概念

| 概念 | 是什么 | 文件 |
| --- | --- | --- |
| **Animation Clip** | 一段动画（关键帧：某个属性在什么时间是什么值） | `.anim` |
| **Animator Controller** | 状态机：哪些 Clip、什么时候切换 | `.controller` |
| **Animator** | 挂在对象上、执行某个 Controller 的组件 | 组件 |

### 创建一个动画

1. 选中对象 → `Window → Animation → Animation` → `Create` → 存到 `Assets/Animations`
2. 点 `Add Property` → 选 `Transform → Scale`（或 `SpriteRenderer → Color`）
3. 时间轴上加关键帧（拖动时间轴 → 改属性 → 自动记录）
4. 设置 `Loop Time`（循环）或单次播放

### 状态机（Animator Controller）

打开 `Window → Animation → Animator`：

| 元素 | 含义 |
| --- | --- |
| 状态（State） | 一段 Clip（比如 Idle、Walk、Jump） |
| 过渡（Transition） | 从 A 到 B 的条件 |
| **参数（Parameters）** | 控制过渡的条件：`Float`、`Int`、`Bool`、`Trigger` |
| `Has Exit Time` | 是否等当前动画播完才切（**角色动作常关掉**） |
| `Transition Duration` | 混合时间（0 = 瞬间切） |

### 代码控制

```csharp
Animator anim = GetComponent<Animator>();

anim.SetBool("isRunning", true);
anim.SetFloat("speed", 5f);
anim.SetInteger("weapon", 2);
anim.SetTrigger("jump");          // 触发一次（自动复位）

anim.Play("Idle", 0);             // 直接跳到某个状态（不走过渡）
anim.speed = 1.5f;                // 动画播放速度
```

### 坑

- **参数名写错不会报错，只是没反应**：用 `Animator.StringToHash("isRunning")` 或检查大小写。
- **过渡条件没设**：默认 `Has Exit Time` 勾着，动画播完才切，看起来像"没反应"。
- **Animator 会覆盖你代码里改的属性**（比如 `transform.localScale`）：动画在跑的时候别再用代码改同一个属性。

## 12.3 实战：同一个动画，两种写法

**目标**：方块数字变化时，先缩小到 0.85 再弹回 1（0.12 秒）。

### 写法 A：协程（推荐，无资源依赖）

```csharp
private IEnumerator PopRoutine()
{
    const float duration = 0.12f;
    float t = 0f;
    while (t < duration)
    {
        t += Time.deltaTime;
        float k = Mathf.Clamp01(t / duration);
        // 用 SmoothStep 让起止更自然
        transform.localScale = Vector3.one * Mathf.Lerp(0.85f, 1f, Mathf.SmoothStep(0f, 1f, k));
        yield return null;
    }
    transform.localScale = Vector3.one;
}
```

### 写法 B：Animator

1. 在方块 Prefab 上建 Animator Controller，加一个 `Pop` 状态（Scale 0.85 → 1，0.12 秒，Loop 关）
2. 加一个 Trigger 参数 `pop`
3. 代码：

```csharp
[SerializeField] private Animator animator;

public void PlayPop()
{
    animator.SetTrigger("pop");
}
```

**怎么选**：2048 这种"一个 Prefab 用几百次"的场景，协程更省心（不用维护每个实例的 Animator 状态）；角色动作、切武器这种多状态动画，用 Animator。

## 12.4 ParticleSystem：粒子特效

### 它是什么

Unity 内置的特效系统：爆炸、烟雾、火花、星光、下雨……一个组件搞定，不用写代码。

### 常用模块

| 模块 | 控制什么 |
| --- | --- |
| `Main` | 持续时间、循环、起始生命周期/速度/大小/颜色、模拟空间 |
| `Emission` | 每秒发射多少粒子（`Rate over Time`）、一次性爆发（`Bursts`） |
| `Shape` | 从什么形状发射（点、球、锥、盒） |
| `Color over Lifetime` | 粒子一生的颜色变化（做淡出） |
| `Size over Lifetime` | 大小变化（做扩散/收缩） |
| `Velocity over Lifetime` | 速度变化（做重力/飘动） |
| `Renderer` | 材质、渲染模式（Billboard / Stretched） |

### 代码控制

```csharp
ParticleSystem ps = GetComponent<ParticleSystem>();

ps.Play();                                  // 播放
ps.Stop();
ps.Emit(20);                                // 立刻发射 20 个（做一次性爆点）

var main = ps.main;
main.startColor = Color.yellow;
var emission = ps.emission;
emission.rateOverTime = 50f;
```

### 常见做法

| 需求 | 做法 |
| --- | --- |
| 一次性爆炸 | `Looping` 关掉、`Emission` 用 `Bursts`、在代码里 `Play()` |
| 持续烟雾 | `Looping` 开着、`Rate over Time` 调小 |
| 粒子跟随对象 | `Main → Simulation Space = Local` |
| 让粒子不受时间缩放影响 | `Main → Use Unscaled Time` |

### 坑

- **看不见粒子**：材质丢了（粉色）、`Play On Awake` 关了但没手动 Play、或者 `Start Lifetime` 太短。
- **性能**：手机上粒子数控制在几百以内；大量子弹/特效考虑对象池。

## 12.5 LineRenderer 与 TrailRenderer

### LineRenderer：画折线

```csharp
LineRenderer lr = GetComponent<LineRenderer>();
lr.positionCount = 3;
lr.SetPosition(0, new Vector3(0, 0, 0));
lr.SetPosition(1, new Vector3(1, 1, 0));
lr.SetPosition(2, new Vector3(2, 0, 0));
lr.startWidth = 0.1f;
lr.endWidth = 0.1f;
lr.material = lineMaterial;         // 必须有材质，否则粉色/不可见
```

**用处**：画轨迹、连线、瞄准线、圈范围。

### TrailRenderer：拖尾

挂在移动的物体上，自动留残影（导弹、快速移动的角色）。

| 属性 | 含义 |
| --- | --- |
| `Time` | 拖尾长度（秒） |
| `Width Curve` | 宽度变化 |
| `Color Gradient` | 颜色渐变（做淡出） |
| `Emitting` | 是否产生拖尾 |

## 12.6 SpriteMask：2D 遮罩

### 它是什么

用一个 Sprite 的形状去"挖洞"或"裁剪"其他的 SpriteRenderer（比如圆形头像框、局部显形效果）。

### 用法

1. 建一个带 `SpriteMask` 组件的对象（任意 Sprite）
2. 设置 `Alpha Cutoff`（透明部分怎么算）
3. 设置 `Front` / `Back` 的内外排序范围（哪些 Sprite 被遮罩影响）
4. 被遮罩的 SpriteRenderer 把 `Mask Interaction` 设成 `Visible Inside Mask` 或 `Visible Outside Mask`

### 坑

- 遮罩只影响 SpriteRenderer，**不影响 UI**（UI 用 Mask / RectMask2D）。
- 排序范围（Front/Back）没设对 → 遮罩"没生效"。

## 12.7 声音：AudioSource

### 它是什么

播放声音的组件。场景里还要有一个 `AudioListener`（摄像机默认自带）代表"耳朵"。

### 关键属性

| 属性 | 含义 |
| --- | --- |
| `AudioClip` | 播放哪个音频 |
| `Play On Awake` | 启动时自动播放（做背景音乐时开） |
| `Loop` | 循环 |
| `Volume` | 音量（0~1） |
| `Spatial Blend` | 0 = 2D 声音（不随位置变化），1 = 3D 声音（有距离衰减） |
| `Min Distance` / `Max Distance` | 3D 声音的衰减范围 |
| `Output` | 输出到哪个 Audio Mixer |

### 代码怎么用

```csharp
AudioSource source = GetComponent<AudioSource>();

source.clip = bgmClip;
source.loop = true;
source.Play();                          // 同一个 clip 重复调用不会重启动

source.PlayOneShot(hitClip, 0.8f);      // 短音效（可叠加，不打断 BGM）
source.Stop();

// 全局音量（0~1）
AudioListener.volume = 0.5f;
```

### 什么时候用哪个

| 需求 | 用 |
| --- | --- |
| 背景音乐（循环） | `Play()` + `loop = true` |
| 一次性音效（点击、合并、爆炸） | `PlayOneShot()` |
| 需要精确控制播放位置/暂停 | `Play()` + `time` 属性 |
| 3D 声音（远处声音小） | `Spatial Blend = 1` |

### 坑

- **多个音效互相打断**：用 `PlayOneShot`，不要共用同一个 `Play()`。
- **场景里没有 AudioListener**：完全没声音（摄像机被删/换了会这样）。
- 音效文件太大：`.wav` 未压缩，用 `.ogg` 或导入设置里压缩。
- **播放前先 `Play()` 再改 `clip`**：无效，改完 clip 要重新 Play。

## 12.8 VideoPlayer（简述）

播放视频（开场动画、过场）。

| 属性 | 含义 |
| --- | --- |
| `Video Clip` | 视频文件 |
| `Render Mode` | `Camera Far Plane` / `Render Texture` / `Material Override` |
| `Audio Output` | 从哪出声音 |

```csharp
VideoPlayer vp = GetComponent<VideoPlayer>();
vp.loopPointReached += _ => Debug.Log("播放结束");
vp.Play();
```

**坑**：移动端视频编码格式限制多；WebGL 需要特殊处理。做 2048 用不到。
