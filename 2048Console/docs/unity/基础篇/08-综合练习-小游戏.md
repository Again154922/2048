# 08　综合练习：做一个完整的"接球"小游戏

这一章不再讲新概念（除了 2D 物理的触发检测），而是**把前面七章的东西串起来做成一个能玩的完整游戏**。做完它，你就走通了"从空项目到能玩"的全流程，之后做 2048 会轻松很多。

## 8.1 目标：玩法与验收标准

**玩法**：方块从天上随机掉落，你操作底部的挡板左右移动去接住它们。

- 接住 → 分数 +1，播放音效
- 漏掉 → 生命 -1，播放音效
- 生命归零 → 游戏结束，显示"本局得分 / 历史最高"，可以重开
- 随时间推移，掉落越来越快

**做完你应该会看到**：一只挡板、不停掉落的方块、实时更新的分数和生命、接住时有反馈、死掉后有结算面板和最高分。

## 8.2 建项目、建场景、分目录

1. Hub 新建项目：模板 **2D (Built-In Render Pipeline)**，名字 `CatchGame`，位置 `F:\unity`
   - 模板选 **2D (Built-In Render Pipeline)**（你的 2022.3 一定有这个模板）
   - 万一误选了 URP 模板（`Universal 2D`），看 8.7 结尾的处理办法
2. `File → Save Scene As`，保存到 `Assets/Scenes/Game.unity`
3. 在 `Assets` 下建目录：`Scripts`、`Prefabs`、`Sprites`、`Audio`

## 8.3 搭场景

### 摄像机

选中 `Main Camera`：

- Position `(0, 0, -10)`
- Projection 保持 `Orthographic`，**Size = 6**（可见高度 12 个单位，宽度约 21）

我们的世界坐标设计：**x 范围大约 ±7.5，y 范围 ±6**，具体下面每个对象都会给数字，照着填就行。

### 背景（可选，但建议做）

1. `2D Object → Sprites → Square`，命名 `Background`
2. Position `(0, 0, 0)`，Scale `(22, 12, 1)`
3. SpriteRenderer 的 Color 设成深蓝灰（比如 `#2B3245`）
4. **Order in Layer 设成 `-10`**（让它永远在最下面）

### 挡板（玩家）

1. `2D Object → Sprites → Square`，命名 `Player`
2. Position `(0, -4.5, 0)`，Scale `(1.6, 0.35, 1)`
3. SpriteRenderer Color 设成青色之类显眼颜色
4. Add Component → **`Box Collider 2D`**，勾上 **`Is Trigger`**
5. Add Component → `PlayerController`（脚本下一步写）

> **为什么玩家用 `Is Trigger`**：Trigger 表示"这个碰撞体只用来检测重叠，不参与物理推挤"。我要的是"碰到就接住了"，不是"把方块弹飞"。

### 生成器（空对象）

1. `Create Empty`，命名 `Spawner`，Position `(0, 0, 0)`
2. Add Component → `Spawner`（脚本稍后写）

### 掉落物 Prefab

1. `2D Object → Sprites → Square`，命名 `Faller`
2. Position `(0, 0, 0)`，Scale `(0.7, 0.7, 1)`，Color 设成暖色（橙色/黄色）
3. Add Component → **`Rigidbody 2D`**：
   - `Body Type` = `Dynamic`
   - `Gravity Scale` = `1`
   - **`Constraints` → 勾上 `Freeze Rotation Z`**（不勾的话方块会边掉边翻跟头）
4. Add Component → **`Box Collider 2D`**，勾上 **`Is Trigger`**
5. Add Component → `Faller`（脚本稍后写）
6. 把 `Faller` 从 Hierarchy **拖进 `Assets/Prefabs`** 生成 Prefab，然后删掉场景里的那个实例

> **`Rigidbody2D` 是什么**：让对象"受物理引擎控制"。`Dynamic` + `Gravity Scale` 就是"受重力下落"。这里用它比自己写 `position.y -= speed * deltaTime` 更省事，而且以后想做反弹、碰撞都会用到。

## 8.4 玩家控制

新建 `Assets/Scripts/PlayerController.cs`：

```csharp
using UnityEngine;

/// <summary>挡板：左右移动，接住掉落物。</summary>
public class PlayerController : MonoBehaviour
{
    [SerializeField] private float speed = 9f;        // 每秒移动多少个世界单位
    [SerializeField] private float limitX = 7.2f;     // 左右边界

    void Update()
    {
        // GetAxisRaw("Horizontal") 返回 -1 / 0 / 1：A、D、←、→ 都能用
        float input = Input.GetAxisRaw("Horizontal");

        Vector3 pos = transform.position;
        pos.x += input * speed * Time.deltaTime;      // 乘 deltaTime，帧率无关
        pos.x = Mathf.Clamp(pos.x, -limitX, limitX);  // 卡住边界，别跑出屏幕
        transform.position = pos;
    }

    // 接住掉落物：只要两方的 Collider 里有一个是 Trigger，就会走这个回调
    private void OnTriggerEnter2D(Collider2D other)
    {
        if (!other.TryGetComponent<Faller>(out _)) return;   // 只处理掉落物

        GameManager.Instance.OnCatch();
        Destroy(other.gameObject);
    }
}
```

**几个要点**：

- `Input.GetAxisRaw("Horizontal")` 比手写 `GetKey(KeyCode.A) || GetKey(KeyCode.LeftArrow)` 简洁，且**默认就绑定了 A/D 和左右方向键**（可以在 `Project Settings → Input Manager` 里看到）
- `Mathf.Clamp(value, min, max)`：把值夹在范围内，做边界限制的标准工具
- `TryGetComponent<T>(out _)`：判断"这个碰撞体身上有没有 `Faller` 组件"，返回 bool 且**不分配内存**。比 `other.GetComponent<Faller>() != null` 好（后者如果没找到会返回 null，且老写法会有 GC 开销）

## 8.5 掉落物

新建 `Assets/Scripts/Faller.cs`：

```csharp
using UnityEngine;

/// <summary>一个掉落物：掉出屏幕下方就通知游戏并销毁自己。</summary>
public class Faller : MonoBehaviour
{
    private const float BottomY = -6.5f;      // 掉到这个高度以下就当作"漏了"

    void Update()
    {
        if (transform.position.y < BottomY)
        {
            GameManager.Instance.OnMiss();
            Destroy(gameObject);
        }
    }
}
```

**为什么用 `const float` 而不是 `[SerializeField]`**：这个值是"游戏规则"的一部分（屏幕底部），不是设计师要反复调的美术参数，写死在代码里更清楚。

## 8.6 生成器与"难度曲线"

新建 `Assets/Scripts/Spawner.cs`：

```csharp
using System.Collections;
using UnityEngine;

/// <summary>按时间间隔在顶部随机位置生成掉落物，越到后面越快。</summary>
public class Spawner : MonoBehaviour
{
    [SerializeField] private GameObject fallerPrefab;   // 把 Faller.prefab 拖进来
    [SerializeField] private float spawnY = 6.5f;       // 生成高度（屏幕上方）
    [SerializeField] private float rangeX = 7f;         // 水平随机范围
    [SerializeField] private float startInterval = 1.0f; // 开局间隔
    [SerializeField] private float minInterval = 0.32f;  // 最快间隔
    [SerializeField] private float rampSeconds = 60f;    // 多久达到最难

    private float _elapsed;

    void Start()
    {
        StartCoroutine(SpawnLoop());
    }

    private IEnumerator SpawnLoop()
    {
        _elapsed = 0f;

        while (true)
        {
            // elapsed / rampSeconds 从 0 涨到 1，用它插值出当前间隔
            float difficulty = Mathf.Clamp01(_elapsed / rampSeconds);
            float interval = Mathf.Lerp(startInterval, minInterval, difficulty);
            yield return new WaitForSeconds(interval);

            if (GameManager.Instance == null || !GameManager.Instance.IsPlaying)
            {
                continue;                       // 没在游戏中就不生成，但仍然在循环（等游戏开始）
            }

            _elapsed += interval;

            Vector3 position = new Vector3(Random.Range(-rangeX, rangeX), spawnY, 0f);
            GameObject go = Instantiate(fallerPrefab, position, Quaternion.identity);

            // 顺带把重力也随难度加大，让"掉得更快"看得见
            Rigidbody2D rb = go.GetComponent<Rigidbody2D>();
            rb.gravityScale = Mathf.Lerp(0.7f, 2.4f, difficulty);
        }
    }
}
```

**协程里的 `while (true)` 不是死循环**——每轮都有 `yield return` 让出执行权，引擎会在下一帧/等待时间结束后继续。

**`Mathf.Lerp(a, b, t)`**：按比例 `t`（0~1）在 a 和 b 之间插值。做"渐变"的标准工具，你以后会天天用到。

> **如果发现 `Random.Range` 和 `System.Random` 打架**：`unity` 里的 `Random` 是 `UnityEngine.Random`。如果文件同时 `using System;` 就会有歧义，这时写全名 `UnityEngine.Random.Range(...)`。

## 8.7 2D 物理：Trigger 检测是怎么回事

这是本章唯一的新概念。2D 物理有三个组件：

| 组件 | 作用 |
| --- | --- |
| `Rigidbody2D` | "我要受物理控制"（重力、速度、碰撞反应）。**它是物理世界的"参赛者"** |
| `Collider2D` | "我的碰撞形状长什么样"（`Box` 方块 / `Circle` 圆 / `Polygon` 多边形） |
| `Physics2D` 设置 | 全局的重力、图层碰撞矩阵等 |

### 触发（Trigger）vs 碰撞（Collision）

| | 勾了 `Is Trigger` | 不勾 |
| --- | --- | --- |
| 物理效果 | **不阻挡**，两个物体直接穿过去 | 会互相弹开、挡住 |
| 回调 | `OnTriggerEnter2D` / `Stay` / `Exit` | `OnCollisionEnter2D` / `Stay` / `Exit` |
| 典型用途 | 拾取道具、进入区域、**接住东西** | 撞墙、球弹地板 |

我们要"碰到就算接住、不把方块弹飞"，所以**两边都勾 `Is Trigger`**。

### 触发检测的三个硬性条件

1. **参与的至少一方要带 `Rigidbody2D`**（我们的掉落物有 Dynamic 刚体 ✓；挡板没有刚体也没关系）
2. 双方的 `Collider2D` 中，**至少一个是 Trigger**
3. 双方在 `Physics2D` 的图层碰撞矩阵里是允许碰撞的（默认都允许，不用管）

### 回调的顺序与"只触发一次"

```csharp
private void OnTriggerEnter2D(Collider2D other)  // 刚重叠的那一帧，只调用一次
private void OnTriggerStay2D(Collider2D other)   // 重叠期间每帧调用
private void OnTriggerExit2D(Collider2D other)   // 分开的那一帧调用一次
```

我们在 `Enter` 里处理"接住"，并且**立刻 `Destroy` 掉落物**——不销毁的话下一帧还会 `Stay`，分数就会一直涨。

> **如果你用了 URP 模板**（`Universal 2D`）：Sprite 默认材质是"受光照"的，场景里没有光源时所有方块都是黑的。解决办法二选一：
> ① 菜单 `GameObject → Light → Global Light 2D` 加一个全局光；
> ② 选中每个 Sprite，把 `SpriteRenderer` 的 `Material` 改成 `Sprite-Unlit-Default`。
> 推荐第一种，一次搞定。

## 8.8 游戏总管：GameManager

分数、生命、游戏状态这些东西"好多脚本都要访问"，需要一个中心。最省事的做法是**单例**：

```csharp
public static GameManager Instance { get; private set; }
```

任何脚本都能写 `GameManager.Instance.OnCatch()` 来通知它。**什么时候不该用单例**：当你的游戏变复杂、需要多个独立场景时，单例会变成"全局变量地狱"。现在这个规模用它最省事，以后学到事件系统再重构也不迟。

新建 `Assets/Scripts/GameManager.cs`：

```csharp
using TMPro;
using UnityEngine;
using UnityEngine.UI;

/// <summary>分数、生命、局状态、UI 刷新、最高分存档，都归它管。</summary>
public class GameManager : MonoBehaviour
{
    public static GameManager Instance { get; private set; }

    [SerializeField] private TextMeshProUGUI scoreText;
    [SerializeField] private TextMeshProUGUI livesText;
    [SerializeField] private TextMeshProUGUI bestText;
    [SerializeField] private GameObject gameOverPanel;
    [SerializeField] private TextMeshProUGUI gameOverText;
    [SerializeField] private Button restartButton;
    [SerializeField] private AudioSource audioSource;
    [SerializeField] private AudioClip catchClip;      // 可选，没有就留空
    [SerializeField] private AudioClip missClip;       // 可选

    private const int MaxLives = 3;
    private const string BestKey = "catch_best";

    private int _score;
    private int _lives;
    private int _best;

    /// <summary>是否正在游戏中（生成器和碰撞回调都会读它）。</summary>
    public bool IsPlaying { get; private set; }

    void Awake()
    {
        Instance = this;
        _best = PlayerPrefs.GetInt(BestKey, 0);       // 读历史最高
        restartButton.onClick.AddListener(StartGame);
    }

    void Start()
    {
        StartGame();
    }

    /// <summary>开始（或重开）一局。</summary>
    public void StartGame()
    {
        ClearFallingObjects();       // 清掉上一局残留的掉落物

        _score = 0;
        _lives = MaxLives;
        IsPlaying = true;

        gameOverPanel.SetActive(false);
        RefreshUI();
    }

    /// <summary>接住一个（由挡板调用）。</summary>
    public void OnCatch()
    {
        if (!IsPlaying) return;

        _score++;
        if (_score > _best)
        {
            _best = _score;
            PlayerPrefs.SetInt(BestKey, _best);
            PlayerPrefs.Save();
        }

        PlaySound(catchClip, 0.8f);
        RefreshUI();
    }

    /// <summary>漏掉一个（由掉落物调用）。</summary>
    public void OnMiss()
    {
        if (!IsPlaying) return;

        _lives--;
        PlaySound(missClip, 0.7f);
        RefreshUI();

        if (_lives <= 0)
        {
            EndGame();
        }
    }

    private void EndGame()
    {
        IsPlaying = false;
        gameOverText.text = $"游戏结束\n本局 {_score}\n最高 {_best}";
        gameOverPanel.SetActive(true);
    }

    private void RefreshUI()
    {
        scoreText.text = $"分数 {_score}";
        livesText.text = $"生命 {new string('♥', Mathf.Max(_lives, 0))}";
        bestText.text = $"最高 {_best}";
    }

    private void PlaySound(AudioClip clip, float volume)
    {
        if (clip != null && audioSource != null)
        {
            audioSource.PlayOneShot(clip, volume);
        }
    }

    private void ClearFallingObjects()
    {
        Faller[] fallers = FindObjectsByType<Faller>(FindObjectsSortMode.None);
        foreach (Faller f in fallers)
        {
            Destroy(f.gameObject);
        }
    }
}
```

**注意 `ClearFallingObjects` 里的 API**：

- Unity 2022.3 及更早：`FindObjectsOfType<Faller>()`
- 从 2022.2 起官方推荐用 `FindObjectsByType<T>(FindObjectsSortMode.None)` 代替 `FindObjectsOfType`：排序模式必须显式给，`None` 表示不排序、最快。上面的代码用的就是它
- 这类"查找所有对象"的操作比较慢，所以只在**开局/重开**这种低频时机调用

## 8.9 搭 UI

### Canvas

1. Hierarchy 右键 → `UI → Canvas`（会自动带一个 `EventSystem`，**别删**，按钮点击依赖它）
2. 选中 Canvas，把 `Canvas Scaler` 的 `UI Scale Mode` 改成 **Scale With Screen Size**，参考分辨率 `1920 × 1080`

### 三行文字

依次建三个 `UI → Text - TextMeshPro`，都放在 Canvas 下：

| 名字 | 锚点 | Pos | 内容 | 说明 |
| --- | --- | --- | --- | --- |
| `ScoreText` | `top-left` | `(40, -40)` | 分数 0 | 左上角 |
| `LivesText` | `top-right` | `(-40, -40)` | 生命 ♥♥♥ | 右上角（右对齐更整齐） |
| `BestText` | `top-left` | `(40, -120)` | 最高 0 | 分数下面一行 |

字号 48 左右；`LivesText` 把对齐方式设成 `Right`，锚点设 `top-right`，位置填负的 X（因为右锚点的 X 是从右边往左算的）。

### 游戏结束面板

1. 右键 Canvas → `UI → Panel`，命名 `GameOverPanel`，颜色调成**半透明黑**（Color 的 A 改成 200 左右）
2. 在它下面加一个 `Text - TextMeshPro`（命名 `GameOverText`，内容先随便写），字号 64、居中
3. 再加一个 `UI → Button - TextMeshPro`，命名 `RestartButton`，把按钮里的文字改成 `再来一局`
4. 选中 `GameOverPanel`，**在 Inspector 左上角取消勾选**（让它默认隐藏）

> 按钮那个 `EventSystem` 是自动生成的，如果你手动删过它，按钮就点不动了——这是新手常见问题之一。

## 8.10 把 GameManager 装配起来

1. Hierarchy → `Create Empty`，命名 `Game`，Position `(0,0,0)`
2. 给 `Game` 挂两个组件：
   - `Audio Source`（**取消勾选 `Play On Awake`**）
   - `GameManager`（脚本）
3. 选中 `Game`，在 Inspector 的 `GameManager` 里**逐个拖引用**（这一步最容易漏，漏了会 `NullReferenceException`）：

| 字段 | 拖什么进来 |
| --- | --- |
| `Score Text` | Canvas/ScoreText |
| `Lives Text` | Canvas/LivesText |
| `Best Text` | Canvas/BestText |
| `Game Over Panel` | Canvas/GameOverPanel |
| `Game Over Text` | Canvas/GameOverPanel/GameOverText |
| `Restart Button` | Canvas/GameOverPanel/RestartButton |
| `Audio Source` | `Game` 自己（把 `Game` 这个对象从 Hierarchy 拖到字段上） |
| `Catch Clip` / `Miss Clip` | 暂时留空（没音效不影响运行） |

4. 选中 `Spawner`，把 `Faller.prefab` 拖到它的 `Faller Prefab` 字段
5. 选中 `Player`，确认 `PlayerController` 上的默认值（速度 9、边界 7.2）合适

## 8.11 音效（可选）

没音效游戏也能玩（代码里对 `clip == null` 做了判断）。想要声音：

1. 从 freesound.org、opengameart.org 下载两个短音效（一个"叮"，一个"哎"），拖进 `Assets/Audio`
2. 把文件拖到 `GameManager` 的 `Catch Clip` / `Miss Clip` 字段

`PlayOneShot` 的好处是**多个音效可以重叠播放**，快节奏时不会互相打断。

## 8.12 验收与扩展

### 验收清单

点 ▶ 后依次确认：

- [ ] 橙色方块从上方随机位置落下
- [ ] 按 A/D 或 ←/→ 挡板左右移动，到边界会停住
- [ ] 接住方块：分数 +1，方块消失
- [ ] 漏掉方块：生命减少，方块在屏幕下方消失
- [ ] 时间越久，方块掉得越快、间隔越短
- [ ] 生命归零：弹出结算面板，显示本局和最高分
- [ ] 点"再来一局"：分数归零、生命恢复、面板隐藏、场上残留的方块被清掉
- [ ] 退出 Play 再进：**最高分还在**（`PlayerPrefs` 生效）

### 出问题先查这里

| 现象 | 原因 |
| --- | --- |
| 方块掉下来但接不住 | 挡板没勾 `Is Trigger`，或者掉落物没有 `Rigidbody2D`（触发检测需要至少一方有刚体） |
| 一接住分数狂涨 | 忘了 `Destroy(other.gameObject)`，或者把逻辑写在了 `OnTriggerStay2D` 里 |
| 方块边掉边翻滚 | `Rigidbody2D` 的 `Constraints` 没勾 `Freeze Rotation Z` |
| 报 `NullReferenceException` 在 `GameManager` | 8.10 表格里的引用没拖全 |
| 方块是黑的 | 用了 URP 模板但没加 `Global Light 2D`（见 8.7 结尾） |
| `Input` 相关报错 | `Active Input Handling` 被改成了 `Input System Package (New)`，改成 `Both` 即可 |

### 扩展练习（按难度排序）

1. **加暂停**：按 `Esc` 把 `Time.timeScale` 在 0 和 1 之间切换（注意：`WaitForSeconds` 会被暂停，`WaitForSecondsRealtime` 不会）
2. **加道具**：再做一个 Prefab（比如绿色的、掉得慢的），接住 +3 分。做法：给 `Faller` 加一个 `[SerializeField] private int scoreValue = 1;`，`OnCatch` 接收这个值
3. **加"炸弹"**：黑色的方块，接住扣一条命。体会一下"用同一个 Prefab + 不同参数做不同行为"的写法
4. **难度可视化**：用 `OnDrawGizmos` 画出生成范围，方便你调参数
5. **换成别的玩法**：把"接球"改成"躲球"（掉落物碰到挡板就扣命），只需要改 `OnTriggerEnter2D` 里的几行——**这就是把逻辑和表现分开的好处**

做完扩展 3 和 5，你就已经具备"独立改出一个新玩法"的能力了。
