# 04　编辑器操作与快捷键

基础篇 03讲了"有哪些窗口"，这一章讲"每个窗口怎么用"。**全是肌肉记忆类的东西，边读边在编辑器里点一遍**，比看十遍都强。

## 4.1 Scene 视图：怎么在场景里移动

Scene 视图是你"搭建世界"的地方。三个基本动作：

| 想干什么 | 操作 | 说明 |
| --- | --- | --- |
| **平移**视野（左右上下看） | **按住鼠标中键拖动** | 2D 最常用；也可以按住 `Alt` + 左键拖动 |
| **缩放**视野 | **滚轮** | 缩放中心是鼠标位置，所以先把鼠标放到要放大的地方 |
| **旋转**视野 | 右键拖动（或 `Alt` + 左键，3D 用） | 2D 项目基本不需要，误按了记得按 `2D` 按钮回正 |

两个必须记住的：

1. **`F` 键（Frame Selected）**：选中一个对象后按 `F`，视图立刻聚焦到它身上。找不到自己刚建的对象时，**在 Hierarchy 里点它一下再按 F**，这是最常用的操作，没有之一。
2. **Scene 视图左上角那个 `2D` 按钮**：点亮时视图是"平视 XY 平面"的 2D 模式。做 2D 游戏**永远点亮它**，否则你会在一个斜着的 3D 视角里疑惑"为什么我拖不准"。

## 4.2 五个工具：Q W E R T

键盘左上角这五个键，是你操作对象的全部手段：

| 键 | 工具 | 用途 |
| --- | --- | --- |
| `Q` | Hand（手） | 只平移视野，不选对象 |
| `W` | **Move（移动）** | 拖对象改 Position |
| `E` | Rotate（旋转） | 拖圆环改 Rotation（2D 一般只改 Z 轴） |
| `R` | Scale（缩放） | 拖方块改 Scale |
| `T` | Rect（矩形） | 改 UI 元素的尺寸和锚点（做 UI 时用） |

**移动的两种方式，优先用第二种**：

- 在 Scene 视图里拖箭头：直观，但数值是"手抖出来"的，很难精确
- **在 Inspector 的 Transform 里直接填数字**：精确、可复制、可微调 —— 2D 游戏里位置往往有规律（比如 4 个格子间距 1.1），**一律填数字**，别拖

两个拖拽时的辅助：

- 拖动时**按住 `Ctrl`**：按网格步进（比如每次跳 0.25），比自由拖好很多
- 拖动时**按一下 `V`**：顶点吸附，把对象吸附到别的对象的顶点/边缘

## 4.3 Hierarchy 窗口：增删改查对象

| 操作 | 怎么做 |
| --- | --- |
| 新建空对象 | 右键 → `Create Empty`，或 `Ctrl+Shift+N` |
| 新建 2D 对象 | 右键 → `2D Object` → `Sprites/Square` 等 |
| 新建 UI | 右键 → `UI` → `Canvas/Panel/Text - TextMeshPro` 等 |
| 复制对象 | 选中后 `Ctrl+D` |
| 删除 | `Delete` |
| 重命名 | `F2`（或双击名字） |
| 改父子关系 | 把一个对象**拖到另一个对象上**（拖进它下面）；拖到空白处则移出父对象 |
| 展开/收起全部子对象 | `Alt` + 点左侧小三角 |
| 临时隐藏 | 点名字左边的**眼睛**图标（只影响编辑器显示，不影响运行） |
| 临时禁用 | 点名字左边眼睛旁边的**勾选框**（这会真的让对象失效，脚本不再跑） |
| 搜索 | 顶部搜索框，支持按名字和类型 |

## 4.4 Inspector 窗口：改组件

Inspector 显示"当前选中对象的所有组件和字段"。三个高级技巧：

| 技巧 | 怎么做 | 什么时候用 |
| --- | --- | --- |
| **复制组件值到别的对象** | 组件右上角 `⋮` → `Copy Component`，然后在目标对象上 `⋮` → `Paste Component Values` | 调好一个方块的颜色/尺寸后，一键同步给别的对象 |
| **重置组件** | `⋮` → `Reset` | 值改乱了想回到默认 |
| **锁定 Inspector** | 右上角小锁图标 | 想让 Inspector 停在 A 对象上，同时去操作 B 对象（比如用 A 的引用拖到 B 上） |

**运行时的 Inspector**：进入 Play 模式后，Inspector 会实时显示字段当前的值。**这是最好的调试手段之一**——把 `private` 字段加上 `[SerializeField]`，运行时就能在 Inspector 里看着它变，比 `Debug.Log` 直观。

## 4.5 Project 窗口：找资源

| 技巧 | 说明 |
| --- | --- |
| 搜索框输入 `t:Script` | 只列脚本；`t:Prefab`、`t:Scene`、`t:Texture` 同理 |
| 搜索框输入 `Player` | 按名字搜索（支持部分匹配） |
| 右键 → `Show in Explorer` | 在文件管理器里打开该资源所在目录（**排查"文件到底在哪"最快的方式**） |
| 拖动资源到 Inspector 字段 | 最常用的赋值方式 |
| 左上角 `+` → `Create` | 新建脚本/材质/Prefab/文件夹 |

建议一开始就把资源分好目录（`Scripts` / `Prefabs` / `Sprites` / `Scenes` / `Audio`），别都堆在 `Assets` 根下。2048 的脚本不多，但习惯要现在养。

## 4.6 常用快捷键总表（Windows）

**场景与对象**

| 快捷键 | 作用 |
| --- | --- |
| `F` | 聚焦选中对象（最常用） |
| `Q` `W` `E` `R` `T` | 手 / 移动 / 旋转 / 缩放 / 矩形工具 |
| `Ctrl+D` | 复制 |
| `Delete` | 删除 |
| `F2` | 重命名 |
| `Ctrl+Shift+N` | 新建空对象 |
| `Ctrl` + 拖动 | 网格步进 |
| `V`（拖动中按） | 顶点吸附 |
| `Ctrl+Shift+F` | **把主摄像机对齐到当前 Scene 视图**（调整好视角后一键让相机跟着走） |

**窗口**

| 快捷键 | 作用 |
| --- | --- |
| `Shift+Space` | 最大化/还原鼠标所在窗口（想全屏看 Scene 或 Game 时用） |
| `Ctrl+S` | 保存（**场景改动没保存会在标题栏显示 `*`**） |
| `Ctrl+Shift+S` | 另存场景 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |

**运行**

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+P` | 开始 / 停止 Play |
| `Ctrl+Shift+P` | 暂停 |
| `Ctrl+Alt+P` | 单步一帧（暂停状态下用。**调试时序问题神器**） |

## 4.7 导入资源

### 图片

把 PNG 直接**拖到 Project 窗口**里即可。选中后在 Inspector 调：

| 设置 | 什么时候改 |
| --- | --- |
| `Pixels Per Unit` | 默认 100 表示"100 像素 = 1 个世界单位"。想让图在场景里更大，把这个调小（或者调 Transform 的 Scale） |
| `Filter Mode` → `Point (no filter)` | 像素风必须改，否则图是糊的 |
| `Compression` → `None` | 像素风/需要锐利时改 |

**别忘了点 `Apply`**（改了导入设置后右下角会亮起按钮）。

### 音效

`.wav` / `.ogg` / `.mp3` 拖进来就能用。注意：**Unity 里播放音效需要一个 `AudioSource` 组件**，Clip 字段里放音频文件，然后代码里 `PlayOneShot` 或 `Play`。

## 4.8 本章动手

新建一个空场景（`File → New Scene`），然后：

1. `Ctrl+Shift+N` 建一个空对象命名 `Parent`，位置填 `(0,0,0)`
2. 在它下面建两个空对象 `A`、`B`（用右键 → Create Empty，**注意要右键在 Parent 上**，这样才是子对象）
3. 填 `A` 的位置 `(1,1,0)`、`B` 的位置 `(-1,1,0)`，观察它们的 Transform 显示的是**局部坐标**
4. 选中 `Parent`，把它的 Position 改成 `(2,0,0)`，观察两个子对象跟着移动
5. 把 `A` 拖到 Hierarchy 的空白处（拖出 Parent），再拖回去，观察 Inspector 里 Position 数值的变化
6. 按 `F` 聚焦看效果；按 `Shift+Space` 全屏 Scene 视图再按一次还原

做完这六步，"父子关系"和"视图操作"就真的进手了。
