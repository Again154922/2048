# 14　类盘点（二）：引擎入口与工具类

这些类基本都是**静态类**（`Application`、`Screen`、`PlayerPrefs`、`Mathf`…），不需要 `new`，直接 `类名.方法()` 调用。它们是"引擎提供给你的工具箱"。

## 14.1 Application：应用本身

| 成员 | 含义 |
| --- | --- |
| `Application.persistentDataPath` | **可写的持久化目录**（存盘就用它） |
| `Application.dataPath` | `Assets` 目录路径（**打包后只读**） |
| `Application.streamingAssetsPath` | `StreamingAssets` 目录（打包后也能读） |
| `Application.temporaryCachePath` | 临时缓存目录 |
| `Application.Quit()` | 退出应用（**编辑器里无效**） |
| `Application.isPlaying` | 是否在 Play 模式 |
| `Application.runInBackground` | 窗口失焦时是否继续运行 |
| `Application.platform` | 当前平台（`RuntimePlatform.WindowsPlayer` 等） |
| `Application.targetFrameRate` | 目标帧率（-1 = 不限制） |

```csharp
string savePath = Path.Combine(Application.persistentDataPath, "save.json");
Debug.Log(Application.persistentDataPath);      // Windows: C:\Users\<用户>\AppData\LocalLow\<公司>\<产品>\

// 编辑器里也能"退出"
#if UNITY_EDITOR
    UnityEditor.EditorApplication.isPlaying = false;
#else
    Application.Quit();
#endif
```

### 坑

- **别往 `dataPath` 写文件**：打包后在 `Program Files` 里，没有写权限。
- `persistentDataPath` 取决于 `Player Settings` 里的 Company/Product Name——**发布后改了，玩家存档"消失"**。

## 14.2 Screen：屏幕

| 成员 | 含义 |
| --- | --- |
| `Screen.width` / `height` | 当前屏幕像素宽高 |
| `Screen.fullScreen` | 是否全屏 |
| `Screen.SetResolution(w, h, fullscreen)` | 改分辨率（打包后有效） |
| `Screen.orientation` | 屏幕方向（移动端） |
| `Screen.safeArea` | 安全区（刘海屏） |

```csharp
// 计算 2D 摄像机的可视世界宽度（配合 orthographicSize）
float worldHeight = Camera.main.orthographicSize * 2f;
float worldWidth = worldHeight * (float)Screen.width / Screen.height;
```

### 坑

- **`Screen.width` 是像素，不是世界单位**（见 06 章"世界单位 vs 像素"）。
- UI 用 Canvas Scaler 自适应，不要手动用 `Screen` 算 UI 尺寸。

## 14.3 SceneManager：场景切换

```csharp
using UnityEngine.SceneManagement;

SceneManager.LoadScene("Game");              // 按名字加载
SceneManager.LoadScene(1);                   // 按 Build Settings 里的索引
SceneManager.LoadScene("Game", LoadSceneMode.Additive);   // 叠加加载（不卸载当前场景）

Scene current = SceneManager.GetActiveScene();
Debug.Log(current.name);

// 场景加载完成事件
SceneManager.sceneLoaded += OnSceneLoaded;
void OnSceneLoaded(Scene scene, LoadSceneMode mode) { /* ... */ }
```

### 坑

- **场景必须在 `Build Settings → Scenes In Build` 里**，否则 `LoadScene` 报错/黑屏。
- 场景切换会**销毁旧场景的所有对象**，跨场景数据要放在 `DontDestroyOnLoad` 的对象上（或静态字段/存档）。
- 加载是异步的，想要进度条用 `LoadSceneAsync` + `AsyncOperation.progress`。

## 14.4 PlayerPrefs：小数据存储

```csharp
// 存（int / float / string 三种）
PlayerPrefs.SetInt("best", 1024);
PlayerPrefs.SetFloat("volume", 0.8f);
PlayerPrefs.SetString("playerName", "James");
PlayerPrefs.Save();                 // 立刻落盘（不调用的话退出时才写）

// 读（第二个参数是默认值）
int best = PlayerPrefs.GetInt("best", 0);
float vol = PlayerPrefs.GetFloat("volume", 1f);
string name = PlayerPrefs.GetString("playerName", "Player");

// 其他
PlayerPrefs.HasKey("best");
PlayerPrefs.DeleteKey("best");
PlayerPrefs.DeleteAll();            // 慎用：清空所有
```

### 适合 / 不适合

| 适合 | 不适合 |
| --- | --- |
| 最高分、音量、语言、开关 | 存档（地图、背包）——数据量大、结构复杂 |
| 几十个键值 | 需要备份/迁移的数据 |

**Windows 上存在注册表**：`HKCU\Software\<Company>\<Product>`。

## 14.5 Debug 与 Gizmos：调试输出与可视化

### Debug

```csharp
Debug.Log("普通日志");
Debug.LogWarning("警告");
Debug.LogError("错误");
Debug.LogException(ex);                       // 打印异常（带堆栈）

// 只在编辑器里输出（打包后自动去掉，性能友好）
[System.Diagnostics.Conditional("UNITY_EDITOR")]
void LogEditor(string msg) => Debug.Log(msg);
```

### Gizmos（场景里的辅助图形）

```csharp
void OnDrawGizmos()
{
    Gizmos.color = Color.red;
    Gizmos.DrawWireSphere(transform.position, 2f);          // 线框球
    Gizmos.DrawCube(transform.position, Vector3.one);       // 实心方块
    Gizmos.DrawLine(a, b);
    Gizmos.DrawRay(transform.position, Vector3.right * 3f);

    Gizmos.matrix = transform.localToWorldMatrix;           // 让 Gizmos 跟着对象
    Gizmos.DrawWireCube(Vector3.zero, Vector3.one);
}

// 只在选中该对象时画（性能更好）
void OnDrawGizmosSelected() { }
```

**用途**：可视化攻击范围、生成区域、射线、路径点。**改参数立刻能看到**，比打印日志快十倍。

## 14.6 Cursor：鼠标指针

```csharp
Cursor.visible = false;                      // 隐藏系统指针（用自定义准星）
Cursor.lockState = CursorLockMode.Locked;    // 锁定到屏幕中心（FPS 常用）
Cursor.lockState = CursorLockMode.None;
```

| LockMode | 行为 |
| --- | --- |
| `None` | 正常 |
| `Locked` | 锁定在屏幕中心，隐藏 |
| `Confined` | 限制在窗口内 |

## 14.7 Input：输入（重温）

```csharp
// 键盘
Input.GetKeyDown(KeyCode.Space)      // 这一帧刚按下
Input.GetKey(KeyCode.Space)          // 一直按住
Input.GetKeyUp(KeyCode.Space)        // 这一帧刚松开

// 鼠标
Input.GetMouseButtonDown(0)          // 0 左 / 1 右 / 2 中
Input.mousePosition                  // 屏幕像素坐标（左下角 0,0）
Input.mouseScrollDelta               // 滚轮

// 轴（默认绑定了 WASD 和方向键）
Input.GetAxisRaw("Horizontal")       // -1 / 0 / 1
Input.GetAxis("Horizontal")          // 带平滑（-1~1 之间过渡）
Input.GetAxisRaw("Vertical")

// 触屏
Input.touchCount
Input.GetTouch(0).position
```

**记住**：`GetKeyDown` 只在**按下的那一帧**为 true，必须写在 `Update` 里。

## 14.8 Physics2D 与 LayerMask

### Physics2D（静态查询工具）

```csharp
// 射线
RaycastHit2D hit = Physics2D.Raycast(origin, direction, distance, layerMask);

// 范围检测
Collider2D[] hits = Physics2D.OverlapCircleAll(center, radius, layerMask);
Collider2D box = Physics2D.OverlapBox(center, size, angle, layerMask);

// 点/线检测
bool inside = Physics2D.OverlapPoint(point, layerMask);
bool blocked = Physics2D.Linecast(from, to, layerMask);
```

### LayerMask

`LayerMask` 是一个"位掩码"，用来表示"我想检测哪些层"。

```csharp
// 取层号
int ground = LayerMask.NameToLayer("Ground");

// 取掩码（可以一次取多层：GetMask("Ground", "Wall")）
int mask = LayerMask.GetMask("Ground");

// 常用简化
int everything = ~0;               // 所有层
int onlyGround = 1 << ground;      // 只有 Ground 层

// 射线只打 Ground
Physics2D.Raycast(transform.position, Vector2.down, 1f, mask);

// 判断对象是否在层里
bool isGround = ((1 << go.layer) & mask) != 0;
```

> **为什么是位运算**：每一层对应 int 的一个二进制位（第 8 层 = `1 << 8`），掩码就是"哪些位是 1"。`LayerMask.GetMask` 帮你算好，不用手写。

## 14.9 协程相关的几个类

| 名称 | 是什么 | 怎么用 |
| --- | --- | --- |
| `IEnumerator` | 协程方法的返回类型 | `IEnumerator MyRoutine()` |
| `Coroutine` | `StartCoroutine` 的返回值，可用来停止 | `Coroutine c = StartCoroutine(...); StopCoroutine(c);` |
| `WaitForSeconds` | 等 N 秒（受 `timeScale` 影响） | `yield return new WaitForSeconds(0.5f);` |
| `WaitForSecondsRealtime` | 等 N 秒（不受暂停影响） | UI 动画用 |
| `WaitForEndOfFrame` | 等这一帧渲染完 | 截屏、读像素 |
| `WaitForFixedUpdate` | 等下一次物理更新 | 物理相关 |
| `WaitUntil(条件)` / `WaitWhile(条件)` | 等到条件成立/不成立 | `yield return new WaitUntil(() => isReady);` |
| `AsyncOperation` | 异步操作（场景加载） | `yield return SceneManager.LoadSceneAsync("Game");` |

```csharp
IEnumerator FadeOut(CanvasGroup group, float duration)
{
    float t = 0f;
    while (t < duration)
    {
        t += Time.unscaledDeltaTime;
        group.alpha = 1f - Mathf.Clamp01(t / duration);
        yield return null;
    }
    group.alpha = 0f;
}
```

## 14.10 Object 体系：搞清楚谁继承谁

```
UnityEngine.Object              （所有 Unity 对象的基类，有 == 重载、可被 Destroy）
├── GameObject                  （场景里的对象）
├── Component                   （所有组件的基类）
│   ├── Transform
│   ├── Behaviour               （可启停的组件基类）
│   │   ├── MonoBehaviour       ← 你写的脚本
│   │   ├── Collider2D          （可启用/禁用，但物理行为不同）
│   │   └── ...
│   ├── SpriteRenderer          （Renderer 子类）
│   ├── Camera
│   └── ...
└── ScriptableObject            （资源型对象，不挂在场景里）
```

### 关键区别

| | `GameObject` | `Component` | `ScriptableObject` |
| --- | --- | --- | --- |
| 在场景里吗 | ✅ | ✅（属于某个 GameObject） | ❌（是资源文件） |
| 有 Transform 吗 | ✅（自己的） | 取决于类型 | ❌ |
| 能挂到对象上吗 | — | ✅ | ❌（用 `.asset` 引用） |
| 典型用途 | 场景实体 | 能力 | 配置数据（数值表、关卡数据） |

### 那个"== null"的坑

Unity 重载了 `==`：**被 `Destroy` 之后的对象，`obj == null` 是 true**，但 `obj.Equals(null)` 是 false。所以判断"对象是否还在"**用 `== null` / `!= null`**，别用 `ReferenceEquals`。

```csharp
if (target == null) return;      // ✅ 正确（已销毁的对象也判为 null）
if (target is null) return;      // ⚠️ 只判断 C# 的 null，销毁的对象不算
```

## 14.11 JsonUtility：JSON 序列化

```csharp
[System.Serializable]
public class SaveData
{
    public int score;
    public int[] cells;          // 一维数组可以
    public string savedAt;
}

// 对象 → JSON
string json = JsonUtility.ToJson(data, prettyPrint: true);
File.WriteAllText(path, json);

// JSON → 对象
SaveData data = JsonUtility.FromJson<SaveData>(File.ReadAllText(path));
```

### 限制（重要）

| 不能做 | 替代 |
| --- | --- |
| 二维数组 `int[,]` | 展平成一维 |
| `Dictionary` | 拆成两个数组 |
| 属性 `public int Score { get; set; }` | 用字段 |
| `null` 引用类型 | 初始化为空数组/空字符串 |
| 多态 | 手写序列化或用 Newtonsoft.Json |

## 14.12 Resources：为什么尽量别用

`Resources.Load("path")` 能从 `Assets/Resources` 目录加载资源，**看着很方便**，但有三个问题：

1. 所有 `Resources` 下的东西**都会被打包进最终包体**（不管用不用）
2. 加载是同步的，**会卡帧**
3. 官方文档明确说"别用 Resources"，推荐 Addressables

**2048 这种小项目**：直接用 Inspector 引用（`[SerializeField]`）最省事；确实需要运行时按名字加载，再用 `Resources.Load`。
