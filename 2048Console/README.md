# 2048（控制台版）

使用 C# / .NET 10 实现的 2048 游戏，纯控制台绘制。

## 项目结构

| 目录 | 说明 |
| --- | --- |
| `2048Console v2.0/` | 当前开发版本。**所有新改动都在这里，发布也只发它** |
| `2048Console v1.0/` | 最初的版本，已冻结不再改动（移动逻辑是逐种情况分类讨论的写法，保留下来作对比） |
| `2048.sln` | 解决方案文件，包含上面两个项目 |

## 玩法

| 按键 | 作用 |
| --- | --- |
| 方向键 / `W` `A` `S` `D` | 朝该方向移动方块 |
| `R` | 重新开始一局（本局最大值会记入历史最高） |
| `Esc` | 退出，并询问是否保存当前进度 |

棋盘下方一行显示两个数字：左边是**历史最高**（跨局保留），右边是**当前最高**（本局出现过的最大方块）。棋盘被填满且无法再合并时提示游戏结束。

## 存档与记录文件

两个文件都生成在 **exe 所在目录**，可直接打开查看，删掉就等于清零：

| 文件 | 内容 |
| --- | --- |
| `2048-best.txt` | 历史最高，里面只有一个数字。棋盘满到无法移动、按 `R`、按 `Esc` 退出这三种情况都会尝试更新 |
| `2048-save.txt` | 按 `Esc` 退出时选择"保存"才会生成，内容是完整地图（4 行 × 4 个格子，写的是 2、4、8…… 这些显示值，空格记 0） |

启动时如果发现 `2048-save.txt`，会询问"是否继续"，选 `Y` 还原上次的棋盘，选 `N` 则开新局（存档文件会保留，下次启动还会问）。文件被手工改坏（出现非 2 的幂等）时会提示读取失败并直接开新局，不会崩溃。

## 构建与运行

```powershell
# 构建整个解决方案
dotnet build "2048.sln"

# 运行 v2.0
dotnet run --project "2048Console v2.0/2048Console v2.0.csproj"
```

## 发布单文件

win-x64、自包含、不带 pdb 的单文件发布：

```powershell
dotnet publish "2048Console v2.0/2048Console v2.0.csproj" -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:DebugType=None -p:DebugSymbols=false
```

产物在 `2048Console v2.0/bin/Release/net10.0/win-x64/publish/` 下，只有一个 exe。

## 实现要点

- **方块用指数存**：棋盘里 1 表示 2、2 表示 4、11 表示 2048，所以"合并"就是指数加一，显示时用 `1 << 指数` 还原。
- **移动按"线"处理**：四个方向共用一套坐标映射 `GetCell(direction, line, position)`，把网格读成 4 条线后，每条线做一次"压缩 + 合并"（`MergeLine`），再按同样顺序写回，不需要按空格数量分类讨论。
- **每格固定 8 列宽输出**：避免数字位数变少时旧字符残留（比如 `16` 变成 `0` 后留下 `6`）；棋盘总宽 32 列，统计行的"当前最高"据此右对齐到棋盘右下角。
