# 11　组件手册（三）：UI 系统

UI 是 Unity 里最容易出"玄学问题"的部分（点不动、字模糊、换分辨率就乱）。这一章把整套 UI 体系拆开讲。

## 11.1 UI 的三层结构

```
Canvas（画布，UI 的根）
├── Canvas Scaler（缩放策略，决定 UI 在不同分辨率下怎么缩）
├── Graphic Raycaster（让 UI 能接收点击）
└── 各种 UI 元素（Image / Text / Button / Slider ...）

EventSystem（场景里一个就够了，负责把点击分发给 UI）
```

**没有 Canvas，UI 元素不显示；没有 EventSystem，按钮点不动。** 这两个是新手最常见的第一关。

## 11.2 Canvas：三种渲染模式

| Render Mode | 含义 | 适合 |
| --- | --- | --- |
| **Screen Space - Overlay**（默认） | UI 直接盖在屏幕上，不受摄像机影响 | **绝大多数游戏 UI** |
| Screen Space - Camera | UI 渲染到某个摄像机，可被 3D 物体遮挡（配合排序） | 需要和场景物体混合排序 |
| World Space | UI 是场景里的真实物体（有世界坐标，会随摄像机远近变化） | 血条、头顶名字、游戏内面板 |

```csharp
Canvas canvas = GetComponent<Canvas>();
canvas.renderMode = RenderMode.ScreenSpaceOverlay;
canvas.sortingOrder = 10;          // 多个 Canvas 时谁的层级高
```

**多 Canvas 的常见做法**：一个主 Canvas 放游戏 UI，另一个（sortingOrder 更高）放弹窗，避免互相干扰重绘。

## 11.3 Canvas Scaler：UI 在不同分辨率下怎么缩

| 模式 | 行为 | 什么时候用 |
| --- | --- | --- |
| **Constant Pixel Size** | 1 个 UI 单位 = 1 像素，字体大小固定 | 不推荐（高分屏上会很小） |
| **Scale With Screen Size**（推荐） | 按"参考分辨率"等比缩放 | **绝大多数游戏** |
| Constant Physical Size | 按物理尺寸（毫米）缩 | 跨设备显示一致（很少用） |

**推荐配置**：

| 属性                   | 值                           |
| -------------------- | --------------------------- |
| UI Scale Mode        | `Scale With Screen Size`    |
| Reference Resolution | `1920 × 1080`               |
| Screen Match Mode    | `Match Width Or Height`     |
| Match                | `0.5`（宽高各占一半；横屏游戏可以偏 0.5~1） |

> 换分辨率时 UI 跑飞，**先来这里检查**，再看锚点。

## 11.4 Graphic Raycaster 与 EventSystem：为什么点不动

| 组件 | 作用 | 缺了会怎样 |
| --- | --- | --- |
| `Graphic Raycaster`（在 Canvas 上） | 把鼠标/触摸位置转成 UI 点击 | 所有 UI 点不动 |
| `EventSystem`（场景里一个对象） | 分发点击、拖拽、键盘导航事件 | 所有 UI 点不动 |
| `Standalone Input Module`（在 EventSystem 上） | 用旧输入系统驱动事件 | 点不动 |

**排查"按钮点不动"的四步**：

1. 场景里有 `EventSystem` 吗？（新建 Canvas 会自动带，删过就没了）
2. Canvas 上有 `Graphic Raycaster` 吗？
3. 按钮的 `Image` 上 `Raycast Target` 勾着吗？（没勾 = 不可点）
4. 有没有别的 UI（比如全屏的半透明 Image）盖在上面？→ 检查它的 `Raycast Target`，不需要点击就把勾去掉

## 11.5 Image：UI 里的图

| 属性 | 含义 |
| --- | --- |
| `Source Image` | 显示哪张 Sprite |
| `Color` | 染色（白色 = 原色） |
| `Type` | `Simple` / `Sliced`（九宫格）/ `Tiled`（平铺）/ `Filled`（进度条） |
| `Preserve Aspect` | 保持宽高比 |
| `Raycast Target` | 是否接收点击（纯装饰图关掉，省性能也避免挡按钮） |

### 四种 Type 的用处

| Type | 效果 | 场景 |
| --- | --- | --- |
| **Simple** | 直接拉伸整张图 | 大多数情况 |
| **Sliced** | 九宫格拉伸（边角不拉伸） | 圆角面板、按钮底图（**最常用**） |
| Filled | 按 `Fill Amount` 裁剪显示 | 血条、冷却转圈 |
| Tiled | 平铺 | 背景纹理 |

```csharp
Image img = GetComponent<Image>();
img.sprite = someSprite;
img.color = Color.white;
img.fillAmount = 0.5f;              // 只有 Type = Filled 时有效
img.raycastTarget = false;          // 装饰图不挡点击
```

### RawImage

和 Image 的区别：**RawImage 直接用 Texture**（不做 Sprite 的九宫格/填充），适合显示**运行时生成的贴图**（RenderTexture、摄像机画面、视频）。

### 坑

- **UI 图模糊**：Sprite 的 Filter Mode / Compression，或 Canvas Scaler 太小。像素风要 `Point (no filter)` + `None` 压缩。
- **九宫格不生效**：Sprite 的 `Border` 没设（在图片导入设置里设 L/R/T/B），或者 Image 的 Type 不是 `Sliced`。

### Panel 是什么？

UI 菜单里的 `UI → Panel` **不是一种组件**——它是"一个 RectTransform（四角拉伸铺满父级）+ 一个 Image（黑色半透明底）"的快捷组合。

| 默认值 | 说明 |
| --- | --- |
| RectTransform 锚点 | 四角分开（`(0,0)` ~ `(1,1)`），**全屏拉伸** |
| Image Color | 黑色，Alpha = 100（半透明） |
| Raycast Target | ✅ 勾着 |

**典型用途**：弹窗遮罩、设置面板底、游戏结束的暗色背景。

**两个常见坑**：

1. **半透明遮罩挡住了下面的按钮**：它的 `Raycast Target` 默认是开的，所以会拦截点击。弹窗遮罩本来就是要挡的；如果你不希望它拦截，取消勾选即可。
2. **想让 Panel 只占一块区域**：把锚点从拉伸模式改成 `center`（或某个角），再设 `Width / Height`；否则它永远铺满父级。

> **"遮罩 + 弹窗"的标准结构**：`Panel`（全屏、半透明黑、`Raycast Target` ✅）→ 下面放一个 `Image`（深色/白色底、固定尺寸、居中）+ 文字 + 按钮。这样点遮罩时不会误触背后的按钮，也是 `GameOverPanel` 的推荐做法。

## 11.6 文本：TextMeshProUGUI vs TextMeshPro

| | `TextMeshProUGUI` | `TextMeshPro` |
| --- | --- | --- |
| 用在哪 | Canvas 里的 UI（**大多数情况**） | 场景里的世界坐标文本（方块上的数字、头顶名字） |
| 坐标 | RectTransform | Transform |
| 别名 | TMP_Text | TMP（3D 版） |

```csharp
using TMPro;

[SerializeField] private TextMeshProUGUI scoreText;

scoreText.text = $"分数 {score}";
scoreText.color = Color.white;
scoreText.fontSize = 48;
scoreText.alignment = TextAlignmentOptions.Center;
```

### 富文本（TMP 支持）

```csharp
scoreText.text = "分数 <color=#FFD700>1024</color>";
scoreText.text = "<size=120%>大号</size> <b>粗体</b> <i>斜体</i>";
```

### 坑

- **第一次建 TMP 会提示导入 TMP Essentials**，点 `Import TMP Essentials`，否则文字不显示。
- 中文要**中文字体资源**：默认字体不含中文。做法：`Window → TextMeshPro → Font Asset Creator` 用系统中文（比如微软雅黑）生成字体资源，然后在 TMP 的 `Font Asset` 指定。**这是中文项目必做的一步**。
- `TextMeshProUGUI` 和 `TextMeshPro` 不能混挂，用错会导致位置/可见性异常。

## 11.7 Button：最常用的交互组件

### 关键属性

| 属性 | 含义 |
| --- | --- |
| `Interactable` | 是否可点（取消勾选 = 禁用态） |
| `Transition` | 悬停/按下时的视觉反馈：`Color Tint` / `Sprite Swap` / `Animation` |
| `Target Graphic` | 反馈作用在哪个图形上 |
| `Navigation` | 键盘/手柄导航 |
| `OnClick()` | 点击事件列表 |

### 代码绑定（推荐，比 Inspector 连线好维护）

```csharp
using UnityEngine.UI;

[SerializeField] private Button restartButton;

void Awake()
{
    restartButton.onClick.AddListener(OnRestartClicked);
}

void OnDestroy()
{
    restartButton.onClick.RemoveListener(OnRestartClicked);   // 好习惯，防泄漏
}

private void OnRestartClicked()
{
    Debug.Log("重开");
}

// 带参数：用 Lambda（注意捕获的变量生命周期）
button.onClick.AddListener(() => StartLevel(3));
```

### Inspector 连线（简单场景也行）

Button 的 `On Click ()` 列表 → `+` → 拖一个对象进去 → 选脚本里的方法。
**限制**：只能调用 **public 方法**，且参数只能是序列化类型（不能传复杂对象）。

### 坑

- **`Interactable` 关掉后按钮变灰但仍然能点？** 不会，禁用后不响应。
- **点了没反应**：先查 11.4 的四步，再确认 `onClick` 里绑的方法**真的被执行**（在方法里加 `Debug.Log`）。
- 按钮的 `Image` 如果 `Raycast Target` 没勾，点不到。

## 11.8 Toggle / ToggleGroup

```csharp
[SerializeField] private Toggle soundToggle;

void Awake()
{
    soundToggle.isOn = PlayerPrefs.GetInt("sound", 1) == 1;
    soundToggle.onValueChanged.AddListener(OnSoundChanged);
}

private void OnSoundChanged(bool isOn)
{
    AudioListener.volume = isOn ? 1f : 0f;
    PlayerPrefs.SetInt("sound", isOn ? 1 : 0);
}
```

| 用途 | 做法 |
| --- | --- |
| 单选（一组里只选一个） | 给每个 Toggle 的 `Group` 指定同一个 `ToggleGroup` |
| 开关设置项 | 直接用 `isOn` + `onValueChanged` |

## 11.9 Slider

```csharp
[SerializeField] private Slider volumeSlider;

void Awake()
{
    volumeSlider.minValue = 0f;
    volumeSlider.maxValue = 1f;
    volumeSlider.value = PlayerPrefs.GetFloat("volume", 0.8f);
    volumeSlider.onValueChanged.AddListener(OnVolumeChanged);
}

private void OnVolumeChanged(float value)
{
    AudioListener.volume = value;
    PlayerPrefs.SetFloat("volume", value);
}
```

**做血条/进度条**：不要用 Slider（重），用 `Image` 的 `Type = Filled` + `fillAmount`，性能更好。

## 11.10 输入框与下拉框（TMP 版本）

```csharp
using TMPro;

[SerializeField] private TMP_InputField nameInput;
[SerializeField] private TMP_Dropdown difficultyDropdown;

void Awake()
{
    nameInput.onEndEdit.AddListener(OnNameEdited);      // 回车或失焦时触发
    difficultyDropdown.onValueChanged.AddListener(OnDifficultyChanged);
}

private void OnNameEdited(string text)
{
    Debug.Log($"玩家名: {text}");
}

private void OnDifficultyChanged(int index)
{
    Debug.Log($"难度: {difficultyDropdown.options[index].text}");
}
```

### 坑

- **中文输入框打不出中文**：`TMP_InputField` 的 `Content Type` 设成 `Standard`（不要设 `Integer Number` 之类），并且字体资源要含中文。
- 输入法（IME）在部分 Unity 版本上表现不一，**打包后再测**。

## 11.11 ScrollRect：滚动列表

### 结构

```
Scroll View（ScrollRect + Image + Mask 可选）
└── Viewport（RectMask2D，决定可视区域）
    └── Content（内容容器，会随内容大小变化）
        └── 一个个 Item
```

### 关键属性

| 属性 | 含义 |
| --- | --- |
| `Content` | 内容容器（**必须指定**，否则滚不动） |
| `Horizontal` / `Vertical` | 允许哪个方向滚 |
| `Movement Type` | `Unrestricted` / `Elastic` / `Clamped` |
| `Inertia` | 惯性（手指拖完继续滑） |
| `Scroll Sensitivity` | 滚轮灵敏度 |

### 动态生成列表

```csharp
[SerializeField] private RectTransform content;
[SerializeField] private GameObject itemPrefab;

public void BuildList(List<string> items)
{
    // 先清空旧内容
    for (int i = content.childCount - 1; i >= 0; i--)
    {
        Destroy(content.GetChild(i).gameObject);
    }

    foreach (string text in items)
    {
        GameObject go = Instantiate(itemPrefab, content);
        go.GetComponentInChildren<TextMeshProUGUI>().text = text;
    }
}
```

### 坑

- **内容不换行/不排列**：给 Content 加 `Vertical Layout Group` + `Content Size Fitter`（`Vertical Fit = Preferred Size`）。
- **滚不动**：`Content` 的尺寸没有超过 `Viewport`；或者 Content 忘了挂 Layout Group。
- **性能**：几百条以上用 `ScrollRect` + 对象池 / `Loop ScrollRect` 插件；几十条直接生成没问题。

## 11.12 布局组：让 UI 自动排列

| 组件 | 作用 |
| --- | --- |
| `Horizontal Layout Group` | 横排 |
| `Vertical Layout Group` | 竖排 |
| `Grid Layout Group` | 网格排列（设置 Cell Size / Spacing / Constraint） |
| `Layout Element` | 单个元素的布局参数（最小/首选尺寸、是否忽略布局） |
| `Content Size Fitter` | 让容器尺寸"包住内容"（`Preferred Size`） |

### 常见组合

| 需求 | 组合 |
| --- | --- |
| 竖排列表且高度自适应 | `Vertical Layout Group` + `Content Size Fitter (Vertical: Preferred Size)` |
| 网格物品栏 | `Grid Layout Group (Constraint: Fixed Column Count = 6)` |
| 按钮自适应文字 | 按钮的 `Image` 加 `Content Size Fitter` |

### 坑

- **Layout Group 和手动摆位置冲突**：加了布局组的容器，**子对象的 Position 会被覆盖**。想手动摆就别加布局组。
- **改了子对象尺寸不生效**：`Content Size Fitter` 和 `Layout Group` 的 `Child Control Size/Width/Height` 没勾。
- 布局在 `LateUpdate` 才生效，**同一帧内读取尺寸可能不准**：可以用 `LayoutRebuilder.ForceRebuildLayoutImmediate(rect)` 强制刷新。

## 11.13 UI 常用 API 速查

| 想做什么 | 代码 |
| --- | --- |
| 改文字 | `text.text = "..."` / `tmp.text = "..."` |
| 改颜色 | `image.color = c` |
| 显示/隐藏 | `panel.SetActive(false)` 或 `canvasGroup.alpha = 0` |
| 禁用按钮 | `button.interactable = false` |
| 进度条 | `image.fillAmount = 0.5f`（Type=Filled） |
| 屏幕坐标转 UI 坐标 | `RectTransformUtility.ScreenPointToLocalPointInRectangle(rect, screenPos, cam, out Vector2 local)` |
| 让 UI 跟随世界物体 | `worldCam.WorldToScreenPoint(pos)` 再赋给 UI 的 `position` |

## 11.14 常见坑总表

| 现象 | 原因 |
| --- | --- |
| 按钮点不动 | 缺 `EventSystem` / `Graphic Raycaster` / `Raycast Target` 没勾 / 被上层挡住 |
| UI 在不同分辨率下错位 | 锚点错 / Canvas Scaler 不是 Scale With Screen Size |
| 文字模糊 | 字体资源分辨率低 / Canvas Scaler 参考分辨率太小 / Filter Mode |
| 中文显示成方块 | TMP 字体资源不含中文 |
| 图是粉红色 | 材质/Shader 丢失（URP 与 Built-in 混用） |
| UI 不显示 | 不在 Canvas 下 / Canvas 被禁用 / Canvas 的 `Render Mode` 配置错 |
| 布局组件不生效 | 同时手动改了位置 / 未勾子对象控制 / 没加 Content Size Fitter |
